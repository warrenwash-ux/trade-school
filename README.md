# Trade School

One shell, multiple course tracks — real estate, finance & investing, law bar prep, and IT careers, with auto repair coming soon.

Consolidates content previously spread across separate apps (Bar Academy, Property Kings, Market Kings, Investiq, IT Career Academy, lmw-academy) into a single-file HTML app with a shared design system, one dashboard, and per-track progress tracking (localStorage today, Supabase planned).

Live at: https://warrenwash-ux.github.io/trade-school/
