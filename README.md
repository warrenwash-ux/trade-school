# App Academy

One shell, multiple course tracks — real estate, finance & investing, and law bar prep, with auto repair coming soon.

Consolidates content previously spread across separate apps (Bar Academy, Property Kings, Market Kings, Investiq) into a single-file HTML app with a shared design system, one dashboard, and per-track progress tracking (localStorage today, Supabase planned).

Live at: https://warrenwash-ux.github.io/app-academy/
